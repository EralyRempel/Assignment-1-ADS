## Overview
This repository contains the implementation of recursive algorithms in Java. The project is divided into three parts: Numbers, Sequences, and Strings.

### Constraints
- No loops (`for`, `while`) are allowed.
- All tasks must use recursion.

---

## Part 1: Numbers
* **Task 1: Print Digits** - Prints digits of a number one by one.
* **Task 2: Average** - Recursively finds the average of array elements.
* **Task 3: Prime Check** - Checks if a number is prime.
* **Task 4: Factorial** - Calculates n!.

## Part 2: Sequences
* **Task 5: Fibonacci** - Finds the n-th Fibonacci number.
* **Task 6: Power** - Calculates $a^n$.
* **Task 7: Reverse Output** - Prints input sequence in reverse order.

## Part 3: Strings
* **Task 8: Is Digits** - Checks if a string contains only digits.
* **Task 9: Character Count** - Counts total characters in a string.
* **Task 10: GCD** - Finds the Greatest Common Divisor using the Euclidean Algorithm.
